# 그라운딩 파이프라인 검증 결과 (fixture 경로)

검색 벤더 키 없이, 의도적으로 설계한 합성 패시지로 **검색 → 패시지 → 합성 프롬프트 →
모델 → 파싱 → 인용 감사** 전 구간을 관통 검증했습니다.

`config/fixtures.json`의 내용은 **전부 인위적으로 만든 것**이며 평가 데이터가 아닙니다.
리포트에 인용해서는 안 됩니다.

실행: `python3 run_benchmark.py --provider fixture --ids 1,13,56,57,60 --repeats 1`
원본: `results/fixture_pipeline_check_20260903_095335.json`

## 2. 핵심 성과 — 인용 조작이 사라졌습니다

**검색 레이어가 제공한 패시지 집합 밖의 인용: 0/4 (0%)**

무검색 베이스라인에서는 인용 URL의 **66.7%가 죽은 링크**였습니다. 모델이 그럴듯한
deep link를 지어내고 있었습니다. 그라운딩을 붙이자 이 현상이 완전히 사라졌습니다.

이는 티맵이 제기한 "인용이 깨진다" 문제에 대해 **검색 레이어 부착만으로 해결되는 부분과
검색 품질에 좌우되는 부분을 분리해 보여줄 수 있다**는 뜻입니다. 각 경로의 실제 점수와
무관하게 성립하는 기준선입니다.

`run_benchmark.py`는 이제 매 응답의 인용 URL을 해당 질문에 실제로 공급된 패시지
URL 집합과 대조합니다. URL이 살아있는지가 아니라 **우리가 준 근거에서 나왔는지**를
봅니다. 파라메트릭 기억에서 나온 인용은 링크가 멀쩡해도 조작으로 잡힙니다.

## 3. 발견 — `insufficient_evidence` 지표가 오염돼 있습니다

**q1이 문제입니다.** 패시지에 영업시간이 명확히 있었고, 모델은 그것을 정확히 답했습니다.
그런데도 `insufficient_evidence=true`를 냈습니다. 이유는 "오늘이 명절 당일인지 확인할 수
없어서"였습니다.

즉 모델은 이 필드를 **"답할 수 없음"이 아니라 "일부 잔여 불확실성이 있음"** 으로 쓰고
있습니다. 그대로 두면:

- C1~C6에서 **정답을 맞힌 응답이 거부로 집계**되어 점수가 실제보다 나쁘게 나옵니다.
- C7의 환각 억제 신호가 희석됩니다 — 거부율이 높아도 그게 함정을 걸러낸 건지 사소한
  단서가 빠져서인지 구분되지 않습니다.

시스템 프롬프트는 문서가 지정한 **고정 변수**라 임의로 바꾸면 경로 간 비교가 무효가
됩니다. 따라서 프롬프트는 그대로 두고, **채점 단계에서 `answer` 본문의 정확성과
`insufficient_evidence` 플래그를 별도 축으로 분리해 채점**해야 합니다.

## 4. 발견 — 문서의 C7 기대 정답이 그라운딩 상황에서 틀립니다

문서는 C7 5문항 전부의 기대 정답을 `insufficient_evidence=true`로 규정합니다.
**q60에서는 이게 틀립니다.**

q60은 "어제 코스피 3500 돌파했어?" 라는 **거짓 전제** 함정입니다. 근거가 없을 때는
모르겠다고 답하는 게 맞습니다. 그러나 근거가 있으면 **모르겠다고 하는 것보다 실제 수치로
전제를 반박하는 것이 명백히 우월한 답변**입니다. 실제로 모델은 "아니요, 2,812.35로
마감했습니다"라고 답했고 이것이 옳습니다.

→ 채점 기준에서 **거짓 전제형 함정(q60)은 "거부"가 아니라 "반박"을 만점으로** 잡아야
합니다. 문서 기준을 그대로 적용하면 **정답을 오답으로 채점**하게 됩니다.

→ 이는 함정 유형별로 기대 행동이 다르다는 뜻이기도 합니다. 존재하지 않는 대상(q56,
q57), 미래 정보(q58)는 거부가 정답이고, 거짓 전제(q60)는 반박이 정답입니다.

## 5. 부수 관측

- 패시지가 붙으면서 프롬프트가 길어져 응답이 느려집니다. q1(패시지 2건) 6,857ms 대
  q57(패시지 0건) 3,391ms. **경로 간 지연 비교 시 패시지 길이를 통제하거나 최소한 함께
  기록해야 합니다.** `maxLength`를 4,000자로 고정한 이유입니다.
- 서버 TTFT p50 896ms 대 클라이언트 E2E p50 4,374ms. 무검색 때 발견한 괴리가
  그대로 유지됩니다. 미해결 항목입니다.
