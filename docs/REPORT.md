**미확인은 오답이 아니다.** 실제 가격·날짜·장소·제작자·조건을 공개 원문과 대조한 비눈가림 AI 검토이며 영상 재생/사람 독립평가는 하지 않았다.

**주요 토큰·시간은 세 조건 공통 완료 26문항**(N1·N2·B2·B3 제외)으로 비교했다. 정확성·실패는 전체30 분모이며, 실패0 usage를 절감으로 계산하지 않는다. 전체관측 집계도 JSON에 보존했다.

- 사실확인 유지·입력 감소 사례: W1, W2, W3, W4, W5, P2, P3, F5, N3, N5, V1, V3, B5. 정확확인 회귀: F3, N2, V5.
- 기본 web/news 3개·passage 1,200자 / browse 4,000자 → 최적화 2개·800자 / browse 2,000자; videos 3→2개. 필수근거 후속조회 허용.
- 초기 지시이지 API 하드제한/반환문 삭제가 아니다. 도구별 실제 인수·반환 개수/문자수와 모든 후속호출은 상세표에 공개했다. Bing 내부 payload는 미노출.
- **최적화는 설정 효과이지 제품 보장이 아니다.** 1회 관측이며 제품 전체 우위·유의성·항상 절감을 주장하지 않는다.
